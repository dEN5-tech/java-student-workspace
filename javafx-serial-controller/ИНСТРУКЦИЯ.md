# 💡 Простое управление Arduino Uno через JavaFX (COM-порт)

## 1. Скетч для Arduino Uno (`Lesson01_Blink.ino`)

```cpp
int led = 12; // Светодиод подключен к пину 12

void setup() {
  Serial.begin(9600);   // Открываем COM-порт со скоростью 9600
  pinMode(led, OUTPUT); // Пин 12 на вывод
}

void loop() {
  if (Serial.available() > 0) {
    char cmd = Serial.read();

    if (cmd == '1') {
      digitalWrite(led, HIGH); // Включить
      Serial.println("Светодиод включен");
    }
    if (cmd == '0') {
      digitalWrite(led, LOW);  // Выключить
      Serial.println("Светодиод выключен");
    }
  }
}
```

---

## 2. Команды

| Символ | Действие |
| :---: | :--- |
| **`1`** | Зажечь светодиод (Пин 12 HIGH) |
| **`0`** | Погасить светодиод (Пин 12 LOW) |

---

## 3. Как запустить

1. **Arduino:** Скетч уже залит в плату Arduino Uno на порту **COM3**.
2. **JavaFX:** Запустите файл **`run.bat`** в папке:
   `C:\Users\dEN5\java-student-workspace\javafx-serial-controller`
3. В окне введите порт (по умолчанию `COM3`) и нажмите **«Подключиться»**.
4. Нажимайте кнопки **«ВКЛЮЧИТЬ (1)»** и **«ВЫКЛЮЧИТЬ (0)»**.
