## 📖 1. Краткие теоретические сведения
Оператор `switch` передает управление одной из ветвей `case` в зависимости от значения переданного выражения (переменной-селектора).

Ключевые требования к реализации в Java:
- В качестве переменной-селектора для выбора операции рекомендуется использовать тип `char` (например, `switch (operation) { case '+': ... }`) или тип `String`.
- Каждая ветка вычислений должна завершаться оператором `break`, чтобы управление не проваливалось в следующие блоки (fall-through).
- Блок `default` обязателен: он выполняется, если введенный знак операции не совпал ни с одним из предусмотренных вариантов.

## 📋 2. Техническое задание

Разработайте консольную программу на Java, выполняющую базовые арифметические действия над двумя вещественными числами.

### Требования к функционалу:
1. **Ввод данных через `Scanner`:**
   - Запрос у пользователя первого числа (`double`).
   - Запрос знака математической операции (`+`, `-`, `*`, `/`).
   - Запрос у пользователя второго числа (`double`).
2. **Логика вычислений:**
   - Выбор математического действия должен быть реализован **строго через конструкцию `switch`**.
   - Программа должна поддерживать четыре базовые операции:
     - Сложение (`+`)
     - Вычитание (`-`)
     - Умножение (`*`)
     - Деление (`/`)
3. **Обработка ошибок и валидация:**
   - **Деление на ноль:** при попытке разделить на `0` программа не должна выводить некорректные результаты или завершаться аварийно. Необходимо вывести понятное предупреждение об ошибке (например: `«Ошибка: деление на ноль невозможно!»`).
   - **Неизвестная операция:** если введен символ, отличный от поддерживаемых, блок `default` должен вывести сообщение о некорректном операторе.
4. **Вывод результата:**
   - Отображение итогового значения в понятном формате (например: `«Результат: 15.0 + 27.0 = 42.0»`).

## 🛠️ 3. Порядок выполнения работы

1. Создайте класс `Calculator` (или новый `.java` файл) в своем воркспейсе.
2. Подключите класс `java.util.Scanner` для считывания ввода.
3. Объявите переменные для хранения двух операндов (`double num1`, `double num2`), символа операции (`char op`) и результата (`double result`).
4. Организуйте последовательный вывод приглашений ко вводу и считывание значений.
5. Постройте конструкцию `switch (op)`:
   - Ветка `case '+':` сложение.
   - Ветка `case '-':` вычитание.
   - Ветка `case '*':` умножение.
   - Ветка `case '/':` проверка делителя на равенство нулю перед делением.
   - Ветка `default:` обработка неверного символа операции.
6. Протестируйте работу приложения по тестовой таблице.
