## ⚡ Как запускать код в VS Code / Codium:

| Способ | Горячая клавиша | Описание |
| :--- | :--- | :--- |
| **Быстрый запуск** | **`Ctrl + Shift + B`** | Мгновенно компилирует и запускает активный файл в терминале с UTF-8. |
| **Отладка** | **`F5`** | Запуск через Debugger с точками останова (Breakpoints). |
| **Кнопка Play** | **▶** (вверху справа) | Запуск через Code Runner в интерактивном окне. |

## 💡 Полезные советы для студентов:
1. **Как создавать новые задачи?**  
   Создайте файл в папке `src/` (например, `BattleDemo.java`), напишите класс и нажмите **`Ctrl+Shift+B`**.
2. **Интерактивный ввод (`Scanner`)**:  
   Вводите данные прямо в нижней панели «Терминал» и нажимайте `Enter`.
3. **Автосохранение**:  
   Включено автоматически (через 1 секунду после окончания ввода).
