# 📘 ПРАКТИЧЕСКАЯ РАБОТА №1: Сетевое подключение к ESP32 и запрос Ping

**Дисциплина / Модуль:** Разработка клиент-серверных IoT-приложений (JavaFX + ESP32)  
**Инструменты:** VS Code, Scene Builder, Wokwi Simulator, PlatformIO, JavaFX SDK 17+, Unirest.

---

## 1. Цель работы

1. Изучить основы клиент-серверного взаимодействия между **JavaFX** и микроконтроллером **ESP32** в симуляторе **Wokwi**.
2. Развернуть на ESP32 асинхронный HTTP REST-сервер на базе `ESPAsyncWebServer`.
3. Создать графический интерфейс в **Scene Builder** с полями ввода, кнопками и индикаторами статуса.
4. Привязать компоненты интерфейса (`fx:id` и `onAction`) к контроллеру `MainController.java`.
5. Реализовать асинхронные HTTP GET-запросы через библиотеку **Unirest** с измерением задержки связи (Ping / RTT).

---

## 2. Архитектура взаимодействия

```
+--------------------------+                 +--------------------------+
|    JavaFX Клиент         |                 |   Wokwi Gateway (шлюз)   |
|   (Unirest GET /ping)    | ──────────────> |   localhost:4000         |
+--------------------------+                 +--------------------------+
                                                          │ (WebSocket)
                                                          ▼
                                             +--------------------------+
                                             |       ESP32 (Wokwi)      |
                                             |  AsyncWebServer (port 8080)
                                             |    IP: 10.13.37.2        |
                                             +--------------------------+
```

### Зачем нужен Wokwi Gateway?
Симулятор Wokwi работает в изолированной сети (`10.13.37.x`). Утилита `wokwigw.exe` пробрасывает порт вашего компьютера (`localhost:4000`) на виртуальный порт платы (`10.13.37.2:8080`).

## 3. Таблица REST API эндпоинтов

| HTTP Метод | URL | Описание | Формат ответа |
| :--- | :--- | :--- | :--- |
| `GET` | `/` | Проверка готовности сервера | `ESP32_READY` |
| `GET` | `/status` | Статус устройства и время работы | `STATUS:ONLINE;UPTIME=42s` |
| `GET` | `/ping` | Проверка связи и измерение задержки | `PONG` |

## 4. Схема подключения в Wokwi (`diagram.json`)

В первой лабораторной работе используется плата **ESP32 DevKit v4**:

```json
{
  "version": 1,
  "author": "Antigravity",
  "editor": "wokwi",
  "parts": [
    { "type": "board-esp32-devkit-c-v4", "id": "esp", "top": 0.0, "left": 0.0, "attrs": {} }
  ],
  "connections": [
    [ "esp:TX", "$serialMonitor:RX", "", [] ],
    [ "esp:RX", "$serialMonitor:TX", "", [] ]
  ],
  "dependencies": {}
}
```

## 6. Разработка логики контроллера (`MainController.java`)

Откройте `javafx-client/src/com/example/MainController.java` и реализуйте шаги по заданию:

### Шаг 1: Подключение к плате (`handleConnect`)
```java
@FXML
void handleConnect() {
    if (!isConnected) {
        statusLabel.setText("ПОДКЛЮЧЕНИЕ...");

        // 1. Формируем URL
        String url = String.format("http://%s/status", getHost());

        // 2. Асинхронный GET-запрос через Unirest
        Unirest.get(url).connectTimeout(2000).asStringAsync(response -> {
            // 3. Обновление UI через Platform.runLater
            Platform.runLater(() -> {
                if (response != null && response.isSuccess()) {
                    isConnected = true;
                    connectBtn.setText("Отключиться");
                    statusLabel.setText("ПОДКЛЮЧЕНО (" + response.getBody() + ")");
                    statusIndicator.setFill(Color.LIMEGREEN);
                    pingBtn.setDisable(false);
                } else {
                    statusLabel.setText("НЕТ СВЯЗИ");
                    statusIndicator.setFill(Color.RED);
                }
            });
        });
    } else {
        disconnect();
    }
}
```

### Шаг 2: Измерение задержки Ping (`handlePing`)
```java
@FXML
void handlePing() {
    pingResultLabel.setText("Измерение...");
    long startTime = System.currentTimeMillis();

    String url = String.format("http://%s/ping", getHost());
    Unirest.get(url).connectTimeout(2000).asStringAsync(response -> {
        long latency = System.currentTimeMillis() - startTime;
        Platform.runLater(() -> {
            if (response != null && response.isSuccess()) {
                pingResultLabel.setText(String.format("Ответ: %s (%d ms)", response.getBody(), latency));
            } else {
                pingResultLabel.setText("Таймаут пинга");
            }
        });
    });
}
```

## 7. Порядок запуска и проверки

1. **Запуск сетевого шлюза:** выполните `run_gateway.bat`.
2. **Запуск симулятора Wokwi:** откройте `diagram.json` в VS Code и нажмите ▶️ *Start Simulation*.
3. **Сборка и запуск JavaFX:** выполните `javafx-client/build.bat`, затем `javafx-client/run.bat` (или нажмите `F5` в VS Code).
4. Нажмите **"Подключиться"** — убедитесь, что индикатор стал зеленым.
5. Нажмите **"Отправить Ping"** — убедитесь, что получен ответ `PONG` и отображается время отклика.
