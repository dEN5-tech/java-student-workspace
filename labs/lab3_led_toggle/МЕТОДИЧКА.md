# 💡 ПРАКТИЧЕСКАЯ РАБОТА №3: Двустороннее переключение светодиода (ВКЛ / ВЫКЛ)

**Дисциплина / Модуль:** Разработка клиент-серверных IoT-приложений (JavaFX + ESP32)  
**Инструменты:** VS Code, Scene Builder, Wokwi Simulator, PlatformIO, JavaFX SDK 17+, Native Java HTTP (`Client.java`).

---

## 1. Цель работы

1. Изучить работу с состоянием устройства (State Management) при сетевом взаимодействии.
2. Реализовать на ESP32 два маршрута управления: `/led/on` (включение) и `/led/off` (выключение).
3. Создать в **Scene Builder** интерфейс с единой кнопкой-переключателем (Toggle Button) и динамическим индикатором.
4. Привязать компоненты интерфейса (`fx:id` и `onAction`) к `MainController.java`.
5. Реализовать логику переключения состояния светодиода по нажатию одной кнопки с синхронизацией UI.

---

## 2. Архитектура и протокол REST API

| HTTP Метод | URL | Описание | Ответ платы |
| :--- | :--- | :--- | :--- |
| `GET` | `/status` | Опрос состояния платы | `STATUS:LED=ON` или `STATUS:LED=OFF` |
| `GET` | `/led/on` | Включить светодиод | `STATUS:LED_IS_ON` |
| `GET` | `/led/off` | Выключить светодиод | `STATUS:LED_IS_OFF` |

## 3. Схема подключения в Wokwi (`diagram.json`)

Светодиод подключен к пину **GPIO 4** через резистор 220 Ом к `GND`:

```json
{
  "version": 1,
  "author": "Antigravity",
  "editor": "wokwi",
  "parts": [
    { "type": "board-esp32-devkit-c-v4", "id": "esp", "top": 0.0, "left": 0.0, "attrs": {} },
    { "type": "wokwi-led", "id": "led1", "top": -40.0, "left": 120.0, "attrs": { "color": "red" } },
    { "type": "wokwi-resistor", "id": "r1", "top": 20.0, "left": 120.0, "attrs": { "value": "220" } }
  ],
  "connections": [
    [ "esp:4", "led1:A", "green", [ "v0" ] ],
    [ "led1:C", "r1:1", "black", [ "v0" ] ],
    [ "r1:2", "esp:GND.1", "black", [ "v0" ] ]
  ],
  "dependencies": {}
}
```

## 5. Разработка логики контроллера (`MainController.java`)

Откройте `javafx-client/src/com/example/MainController.java` и реализуйте метод переключения:

```java
/**
 * Задание: Двустороннее переключение светодиода
 */
@FXML
void handleToggleLed() {
    if (isLedOn) {
        // 1. Формируем URL для выключения
        String url = makeUrl("/led/off");

        // 2. Отправляем запрос через Client.java
        Client.get(url, response -> {
            if (response.isSuccess()) {
                updateLedUI(false); // Обновляем состояние на ВЫКЛ
            }
        });
    } else {
        // 1. Формируем URL для включения
        String url = makeUrl("/led/on");

        // 2. Отправляем запрос через Client.java
        Client.get(url, response -> {
            if (response.isSuccess()) {
                updateLedUI(true); // Обновляем состояние на ВКЛ
            }
        });
    }
}
```

## 6. Порядок запуска и проверки

1. **Запустите Wokwi Gateway:** `run_gateway.bat`.
2. **Запустите симуляцию:** откройте `diagram.json` и нажмите ▶️.
3. **Запустите клиент:** `javafx-client/build.bat`, затем `javafx-client/run.bat` (или `F5` в VS Code).
4. Нажмите **"Подключиться"** -> кнопка "Включить LED" станет активной.
5. Нажмите **"Включить LED"**:
   * Светодиод в Wokwi загорится.
   * Текст кнопки изменится на **"Выключить LED"**, а индикатор станет зелёным.
6. Нажмите **"Выключить LED"**:
   * Светодиод в Wokwi погаснет.
   * Текст кнопки вернётся в **"Включить LED"**, а индикатор станет серым.
