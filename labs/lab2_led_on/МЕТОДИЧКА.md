# 💡 ПРАКТИЧЕСКАЯ РАБОТА №2: Включение светодиода на ESP32

**Дисциплина / Модуль:** Разработка клиент-серверных IoT-приложений (JavaFX + ESP32)  
**Инструменты:** VS Code, Scene Builder, Wokwi Simulator, PlatformIO, JavaFX SDK 17+, Unirest.

---

## 1. Цель работы

1. Изучить работу с дискретными выходами (GPIO) микроконтроллера ESP32 по сетевому протоколу HTTP REST.
2. Собрать в симуляторе Wokwi схему со светодиодом (`wokwi-led`) и токоограничивающим резистором (220 Ом) на пине **GPIO 4**.
3. Создать в **Scene Builder** графический интерфейс с кнопкой включения и индикатором состояния.
4. Привязать компоненты интерфейса (`fx:id` и `onAction`) к `MainController.java`.
5. Реализовать обработчик нажатия кнопки для отправки HTTP GET-запроса `/led/on` через Unirest.

---

## 2. Архитектура и протокол REST API

| HTTP Метод | URL | Описание | Ответ платы |
| :--- | :--- | :--- | :--- |
| `GET` | `/status` | Опрос состояния платы | `STATUS:LED=OFF` |
| `GET` | `/led/on` | Зажечь светодиод (GPIO 4 = HIGH) | `STATUS:LED_IS_ON` |

---

## 3. Схема подключения в Wokwi (`diagram.json`)

Светодиод подключается к пину **GPIO 4** через резистор 220 Ом к земле (`GND`):

```json
{
  "version": 1,
  "author": "Antigravity",
  "editor": "wokwi",
  "parts": [
    { "type": "board-esp32-devkit-c-v4", "id": "esp", "top": 0.0, "left": 0.0, "attrs": {} },
    { "type": "wokwi-led", "id": "led1", "top": -40.0, "left": 120.0, "attrs": { "color": "red" } },
    { "type": "wokwi-resistor", "id": "r1", "top": 20.0, "left": 120.0, "attrs": { "value": "220" } }
  ],
  "connections": [
    [ "esp:4", "led1:A", "green", [ "v0" ] ],
    [ "led1:C", "r1:1", "black", [ "v0" ] ],
    [ "r1:2", "esp:GND.1", "black", [ "v0" ] ]
  ],
  "dependencies": {}
}
```

## 5. Разработка логики контроллера (`MainController.java`)

Откройте `javafx-client/src/com/example/MainController.java` и реализуйте метод включения светодиода:

```java
/**
 * Задание: Включение светодиода на плате ESP32
 */
@FXML
void handleTurnOnLed() {
    // 1. Формируем URL для эндпоинта /led/on
    String url = String.format("http://%s/led/on", getHost());

    // 2. Отправляем асинхронный GET-запрос
    Unirest.get(url).connectTimeout(2000).asStringAsync(response -> {
        // 3. Обновляем интерфейс в потоке JavaFX
        Platform.runLater(() -> {
            if (response != null && response.isSuccess()) {
                ledIndicator.setFill(Color.LIMEGREEN);
                ledStatusLabel.setText("СВЕТОДИОД ВКЛЮЧЕН");
                btnTurnOnLed.setDisable(true); // Кнопка блокируется, так как LED уже включен
            } else {
                statusLabel.setText("ОШИБКА ОТПРАВКИ КОМАНДЫ");
            }
        });
    });
}
```

## 6. Порядок запуска и проверки

1. **Запуск Wokwi Gateway:** запустите `run_gateway.bat`.
2. **Запуск симуляции:** откройте `diagram.json` и нажмите ▶️ *Start Simulation*.
3. **Запуск клиента:** соберите проект через `javafx-client/build.bat` и запустите через `javafx-client/run.bat`.
4. Нажмите кнопку **"Подключиться"** -> кнопка "Включить LED" станет активной.
5. Нажмите **"Включить LED"**:
   * На схеме в Wokwi светодиод на пине 4 загорится ярким красным светом.
   * В приложении кружок `ledIndicator` станет ярко-зелёным, а текст изменится на "СВЕТОДИОД ВКЛЮЧЕН".
