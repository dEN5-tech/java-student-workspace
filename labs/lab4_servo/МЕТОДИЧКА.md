# ⚙️ ПРАКТИЧЕСКАЯ РАБОТА №4: Управление сервоприводом (0–180°)

**Дисциплина / Модуль:** Разработка клиент-серверных IoT-приложений (JavaFX + ESP32)  
**Инструменты:** VS Code, Scene Builder, Wokwi Simulator, PlatformIO, JavaFX SDK 17+, Native Java HTTP (`Client.java`).

---

## 1. Цель работы

1. Изучить работу с ШИМ (PWM) и сервоприводами на базе библиотеки `ESP32Servo`.
2. Подключить сервопривод `wokwi-servo` к пину **GPIO 18** в симуляторе Wokwi.
3. Реализовать на ESP32 эндпоинт управления углом: `/servo?angle=N` (где $N \in [0, 180]$).
4. Создать в **Scene Builder** интерфейс с ползунком `Slider` и быстрыми кнопками позиционирования (0°, 90°, 180°).
5. Привязать компоненты интерфейса (`fx:id` и `onAction`) к `MainController.java`.
6. Реализовать отправку запросов угла на микроконтроллер при перемещении ползунка в реальном времени.

---

## 2. Архитектура и протокол REST API

| HTTP Метод | URL с параметром | Описание | Ответ платы |
| :--- | :--- | :--- | :--- |
| `GET` | `/status` | Опрос состояния платы | `STATUS:SERVO=90` |
| `GET` | `/servo?angle=0` | Повернуть сервопривод на 0° | `STATUS:SERVO=0` |
| `GET` | `/servo?angle=90` | Повернуть сервопривод на 90° (центр) | `STATUS:SERVO=90` |
| `GET` | `/servo?angle=180` | Повернуть сервопривод на 180° | `STATUS:SERVO=180` |

## 3. Схема подключения в Wokwi (`diagram.json`)

Сервопривод подключается тремя проводами:
* **PWM (Сигнал):** оранжевый провод $\rightarrow$ **GPIO 18**
* **VCC (Питание):** красный провод $\rightarrow$ **5V**
* **GND (Земля):** чёрный провод $\rightarrow$ **GND**

```json
{
  "version": 1,
  "author": "Antigravity",
  "editor": "wokwi",
  "parts": [
    { "type": "board-esp32-devkit-c-v4", "id": "esp", "top": 0.0, "left": 0.0, "attrs": {} },
    { "type": "wokwi-servo", "id": "servo1", "top": -40.0, "left": 150.0, "attrs": {} }
  ],
  "connections": [
    [ "esp:18", "servo1:PWM", "orange", [ "v0" ] ],
    [ "esp:5V", "servo1:V+", "red", [ "v0" ] ],
    [ "esp:GND.1", "servo1:GND", "black", [ "v0" ] ]
  ],
  "dependencies": {}
}
```

## 5. Разработка логики контроллера (`MainController.java`)

Откройте `javafx-client/src/com/example/MainController.java` и реализуйте шаги задания:

### Шаг 1: Подключение слушателя к Slider (`initialize`)
```java
@FXML
public void initialize() {
    statusLabel.setText("ОТКЛЮЧЕНО");
    setControlsDisabled(true);

    // Слушатель изменения положения ползунка
    servoSlider.valueProperty().addListener((obs, oldVal, newVal) -> {
        int angle = newVal.intValue();
        servoAngleLabel.setText(String.format("%d°", angle));
        setServoAngle(angle);
    });
}
```

### Шаг 2: Метод отправки угла на ESP32 (`setServoAngle`)
```java
/**
 * Отправка угла сервопривода по протоколу HTTP REST
 */
private void setServoAngle(int angle) {
    String url = makeUrl(String.format("/servo?angle=%d", angle));
    Client.get(url, null); // Асинхронный запрос в фоне через Client.java
}
```

## 6. Порядок запуска и проверки

1. **Запустите Wokwi Gateway:** `run_gateway.bat`.
2. **Запустите симуляцию:** откройте `diagram.json` и нажмите ▶️.
3. **Запустите клиент:** `javafx-client/build.bat`, затем `javafx-client/run.bat` (или `F5` в VS Code).
4. Нажмите **"Подключиться"** -> слайдер и кнопки станут активными.
5. Двигайте ползунок мышью или нажимайте кнопки **0°**, **90°**, **180°**:
   * В симуляторе Wokwi стрелка сервопривода будет плавно и точно поворачиваться в реальном времени на заданный угол!
