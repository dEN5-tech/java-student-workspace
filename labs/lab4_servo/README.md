# ⚙️ Лабораторная работа №4: Управление сервоприводом (ШИМ) и светодиодом на ESP32

- 📄 **Полная инструкция и теория:** см. [МЕТОДИЧКА.md](МЕТОДИЧКА.md)
- ⚙️ **Сборка прошивки ESP32:** запустите `build_firmware.bat`
- 🌐 **Запуск Wokwi Gateway:** запустите `run_gateway.bat`
- 💻 **Запуск JavaFX Клиента:** запустите `run_client.bat`

### REST Эндпоинты
- `GET /status` — `STATUS:LED=...;SERVO=...`
- `GET /led/on`, `GET /led/off` — управление светодиодом
- `GET /servo?angle=0..180` — установка угла вала сервопривода (ШИМ GPIO 18)
