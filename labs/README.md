# 🎓 Комплекс практических работ: Связка Wokwi ESP32 + JavaFX

Данный репозиторий содержит 4 готовых автономных практических работы по разработке клиент-серверных IoT систем на базе **ESP32** (симулятор **Wokwi**) и десктопных приложений на **JavaFX**.

---

## 📂 Структура лабораторных работ

| Лабораторная работа | Описание | Периферия / Протокол | Документация |
| :--- | :--- | :--- | :--- |
| [📁 **Практическая 1: Подключение и Ping**](lab1_connection/) | Базовое сетевое подключение, GET `/status`, `/ping`, расчет задержки (RTT). | Плата ESP32 (REST API) | [Методичка №1](lab1_connection/МЕТОДИЧКА.md) |
| [📁 **Практическая 2: Включение светодиода**](lab2_led_on/) | Управление дискретным выводом GPIO 4 по запросу GET `/led/on`, смена цвета индикатора в UI. | Светодиод (GPIO 4), Резистор 220 Ом | [Методичка №2](lab2_led_on/МЕТОДИЧКА.md) |

## 🚀 Унифицированный порядок запуска любой лабораторной:

1. **Запуск сетевого шлюза (1 раз):**
   - Откройте папку нужной работы и запустите `run_gateway.bat` (или из корня репозитория).
2. **Запуск симуляции Wokwi:**
   - Откройте папку лабораторной в VS Code и нажмите `F1` $\rightarrow$ **`Wokwi: Start Simulator`** (бинарник `.bin` уже предкомпилирован!).
3. **Запуск клиента JavaFX:**
   - В папке лабораторной запустите `run_client.bat`.
   - В окне нажмите **"Подключиться"** и взаимодействуйте с симуляцией.
