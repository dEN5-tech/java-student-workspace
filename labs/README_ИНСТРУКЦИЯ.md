# 🎓 Практические работы: Управление ESP32 через JavaFX (All-in-One Workspace)

Комплект из **4 практических работ** по разработке клиент-серверных IoT-приложений (JavaFX + ESP32 в симуляторе Wokwi).

---

## ⚡ Быстрый старт (Всё в одном, без установки лишнего ПО)

### Требования на компьютере:
1. **JDK 17 или выше** (для запуска JavaFX).
2. **VS Code** с установленным бесплатным расширением **Wokwi Simulator** (`wokwi.wokwi-vscode`).
3. *(Опционально)* **Scene Builder** для визуального редактирования дизайна FXML.

*(Устанавливать PlatformIO, Maven или компилировать C++ **НЕ ТРЕБУЕТСЯ** — прошивка для ESP32 уже собрана в каждой лабе!).*

---

## 🚀 Как открыть все работы в VS Code (в 1 клик)

1. В VS Code выберите меню **File $\rightarrow$ Open Workspace from File...**
2. Выберите файл **`Wokwi-ESP32-JavaFX-Labs.code-workspace`**.
3. В боковой панели откроются все 4 практические работы:
   * **📘 1. Практическая №1** — Подключение к ESP32 и запрос Ping
   * **💡 2. Практическая №2** — Включение светодиода (GPIO 4)
   * **💡 3. Практическая №3** — Двустороннее переключение LED (ВКЛ / ВЫКЛ)
   * **⚙️ 4. Практическая №4** — Управление сервоприводом (GPIO 18, 0–180°)

---

## 📌 Порядок выполнения любой практической работы

В каждой папке лабораторной работы:

1. **Запустите шлюз Wokwi:** двойной клик по файлу `run_gateway.bat` *(он связывает симулятор с вашим ПК на порту `4000`)*.
2. **Запустите симуляцию ESP32:** откройте `diagram.json` в VS Code и нажмите зеленую кнопку **▶️ Start Simulation**.
3. **Откройте `МЕТОДИЧКА.md`:** следуйте пошаговому руководству:
   * Настройте дизайн в **Scene Builder** (`MainView.fxml`).
   * Реализуйте логику с `// TODO:` в `MainController.java`.
4. **Соберите и запустите клиент:**
   * Собрать: запустите `javafx-client/build.bat` (или выберите задачу в VS Code `Ctrl+Shift+B`).
   * Запустить: запустите `javafx-client/run.bat` (или нажмите `F5` в VS Code).
