# Вариант 5: Кодовый замок СКУД с ИК-пультом
**Специальность:** 09.02.01 «Компьютерные системы и комплексы»  
**Тема курсового проекта:** Разработка аппаратно-программного комплекса микропроцессорной системы на базе Arduino Uno с рабочим местом оператора на JavaFX.

---

## 1. Описание системы
Электронный кодовый замок системы контроля и управления доступом (СКУД). Принимает 4-значный PIN-код с инфракрасного пульта ДУ через приемник TSOP, управляет электромеханическим замком (светодиоды) и ведет журнал событий.

## 3. Протокол связи через COM-порт (9600 бод, 8N1)

### Телеметрия от платы (каждую 1 сек):
Формат строки:
`EVENT:AUTH_OK;CODE:1234;STATUS:GRANTED`

### Команды управления от ПК:
- `UNLOCK` — вызов соответствующей операции на микроконтроллере
- `SET_CODE:5678` — вызов соответствующей операции на микроконтроллере

## 4. Задание для студента (что нужно доработать в JavaFX)
1. Открыть проект в **VS Code** или запустить через `run.bat`.
2. В классе `MainController.java` доработать метод `parseTelemetry(String line)`:
   - Разобрать приходящую строку на составляющие параметры.
   - Красиво отобразить значения на экране (числовые индикаторы, цветные бейджи статуса).
3. Добавить визуализацию (график `LineChart` или таблицу истории `TableView`).
4. Реализовать обработку отправки команд из интерфейса.
5. Проверить совместную работу: запустить Wokwi, включить мост HW VSP3s (COM3) и нажать «Подключиться».
