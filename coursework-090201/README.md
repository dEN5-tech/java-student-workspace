# Курсовое проектирование по специальности 09.02.01 «Компьютерные системы и комплексы»

Добро пожаловать в репозиторий практических заданий и шаблонов курсовых проектов для студентов специальности **09.02.01 «Компьютерные системы и комплексы»**.

---

## 🎯 Архитектура курсового проекта
Каждый проект представляет собой законченный аппаратно-программный комплекс:
1. **Аппаратный микропроцессорный узел (Backend):** Плата Arduino Uno, датчики, индикаторы и исполнительные механизмы, смоделированные в симуляторе **Wokwi** с пробросом последовательного порта по сети (`rfc2217ServerPort = 4000`).
2. **Драйвер виртуального порта (Мост):** Программа **HW VSP3s**, связывающая локальный сетевой сокет `127.0.0.1:4000` с виртуальным портом операционной системы `COM3`.
3. **АРМ Оператора (Frontend):** Настольное графическое приложение на **Java / JavaFX**, взаимодействующее с контроллером через библиотеку `jSerialComm` (обертка `SimpleSerial`).

## 🛠️ Как студенту работать с проектом:
1. Перейдите в папку вашего варианта (например, `variant1_thermostat/`).
2. Ознакомьтесь с файлом **`TASK.md`** — там приведено полное техническое задание и перечень команд.
3. Откройте воркспейс в VS Code (файл `<variant>.code-workspace`).
4. Запустите симуляцию в Wokwi (папка `wokwi/`).
5. В папке `javafx-client/` запустите файл **`run.bat`** для проверки стартового шаблона АРМ оператора.
6. Выполните задание по доработке графического интерфейса и алгоритма обработки данных в файле `MainController.java`.
